## 上下文

解析参数 $ARGUMENTS，提取以下关键信息：

- [组件名称]：从 $ARGUMENTS 中获取按钮名称，转换为帕斯卡命名法（例如：输入“添加待办”，转换为“AddTodo”）
- [按钮描述]：从 $ARGUMENTS 中获取按钮的功能描述，用于组件注释

## 任务要求

按照以下规范创建专属按钮 UI 组件：

1.  组件文件存放路径：`src/components/`（Todo 项目的 UI 组件统一目录）
2.  语法要求：使用 Vue3 `<script setup>` 语法（符合你的 Vue3 Todo 项目技术栈）
3.  组件命名：[组件名称]的帕斯卡命名（例如 AddButton）
4.  核心功能：绑定点击事件 `@click`，并定义占位函数 `onButtonClick`（后续可填充业务逻辑）
5.  直接生成完整可复用的 Vue3 组件代码，无需额外修改即可粘贴使用

## 按钮样式变体

为按钮设计 3 种实用样式变体：

1.  **主按钮（primary）**：默认样式，用于核心操作（如“添加待办”），使用主题变量 `var(--color-primary)`
2.  **危险按钮（danger）**：破坏性操作样式，用于删除/清空操作（如“删除待办”），使用主题变量 `var(--color-danger)`
3.  **成功按钮（success）**：完成状态操作样式，用于标记完成（如“标记已完成”），使用主题变量 `var(--color-success)`

## 组件模板规范

生成的 Vue3 组件必须包含以下内容：

1.  内联样式：基于上述 3 种变体，绑定对应的主题变量，无需额外引入样式文件
2.  Props 定义：
    - `variant`：样式变体属性，默认值为“primary”，支持切换 3 种样式
    - `label`：按钮文字属性，默认值为[组件名称]的中文展示（例如“添加待办”）
3.  结构清晰：包含模板结构、脚本逻辑，注释完整，直接适配你的 Vue3 Todo 项目
